Portfolio Editor

Local content tool — not part of the public site. Edits live in your browser until you export.

Loads the JSON files from ../data/. Run this from a local static server (see the README — npx serve . or python3 -m http.server) so the fetch() calls work; opening the file directly (file://) will block them. When you're done, click Export on a tab and replace the matching file in /data/, then commit.
